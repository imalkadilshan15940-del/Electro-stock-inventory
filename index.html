Not connected
Run start_server.bat on your PC, then enter your file path below and click Connect & Save Path. (For a server that keeps stopping on its own, run Install_AutoStart.bat once instead — see setup instructions below.)
The Python server will read and write all inventory data to this path automatically.
GitHub mode is optional. It lets several laptops share this inventory over the internet with no local server — but every device must be individually connected here (this is a per-device setting, not something one Save button pushes to everyone).
Each user generates their own token on GitHub (Settings → Developer settings → Personal access tokens) with write access to this one repo, and pastes it here on their own device. The token never leaves this browser.
Onboard a new device / new user
Generates a small connection-profile file using this device's current settings above. Give it to a new user — on the very first screen they open, they can load this file instead of typing everything in by hand.
Only used if the new user's data file/repo is completely empty (no admin account yet) — it pre-fills their "create admin" screen so they just have to click through, not type. It never overwrites an existing account. Tell them to change this password after their first login. Use a different one per person if you can — don't reuse the same starter password everywhere.

Setup instructions (click to expand)
Local Python Server — Step 1: install Python from python.org. Step 2: keep electro_stock_server.py, start_server.bat and Install_AutoStart.bat together in one folder. Step 3: enter your save path above and click Connect. Best for a single PC, or several PCs on the same office network/shared drive.
Server keeps stopping / dropping? — Run Install_AutoStart.bat once (double-click it, no admin rights needed). It sets the server to start automatically at every Windows login, run completely hidden, and restart itself within seconds if it ever crashes — so there's no visible window for anyone to accidentally close, and no button to remember to press. Run Uninstall_AutoStart.bat to undo it.
GitHub Repository — No Python or server needed. Create a (private, recommended) GitHub repo, generate a personal access token per device, and fill in the fields above on each laptop that should use the system. Best when laptops are in different locations or you want a proper internet-based multi-user setup.
Onboarding a new device fast — Use "Download connection profile" above, send the file to the new user, and have them click "Load connection profile" on their very first loading screen instead of typing in the repo/path/branch by hand.
With either backend, if two people save at nearly the same moment, the system now warns instead of silently dropping one person's changes — use the Refresh data button in the top bar often when several people are working at once.
